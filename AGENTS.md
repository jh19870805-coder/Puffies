# Project Instructions

This project uses the SPEC workflow maintained under `Documents/`.

Before starting feature work, bug fixes, scene changes, asset/config changes, or any task that changes project behavior:

1. Read `Documents/SPEC_WORKFLOW.md`.
2. Read `Documents/SPEC_STATUS.md`.
3. Follow the workflow and current `Next Action` recorded there unless the user gives a newer instruction.

When code, scene, asset, or configuration changes are made, update `Documents/SPEC_STATUS.md` in the same turn with the relevant progress, checks, and next action. Keep static project information in `Documents/PROJECT_SETUP.md`.

For simple questions or read-only investigation, do not update the SPEC status unless the user explicitly asks.

# Puffies

Unity 2D / URP 卡包开包、拼图拖拽与任务奖励项目。

## 文档入口

| 文件 | 用途 |
|------|------|
| [Documents/PROJECT_CONTEXT.md](Documents/PROJECT_CONTEXT.md) | 功能需求、工程结构、场景、数据、资源与构建规则 |
| [Documents/CURRENT_TASK.md](Documents/CURRENT_TASK.md) | 当前任务状态、检查结果与下一步 |
| [Documents/WORKFLOW.md](Documents/WORKFLOW.md) | Codex 工作流规则与任务模板 |

## 快速约定

- Unity：**2022.3.62f2c1**
- URP：**14.0.12**
- 设计分辨率：**2560 x 1440**
- Build Settings 启动场景：**LoadingScene**
- 文本文件编码：**UTF-8**

开发前先读 `Documents/WORKFLOW.md` 与 `Documents/CURRENT_TASK.md`；涉及功能、代码、场景、资源或配置变更时，同步 `Documents/CURRENT_TASK.md`。
